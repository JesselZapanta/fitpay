## Notes
- **JWT choice**: User explicitly requested `jwt` (not Sanctum) in second prompt — installed `tymon/jwt-auth 2.3` (compatible Laravel 12, PHP 8.2), `JWT_TTL 60` / `refresh_ttl 20160`, blacklist enabled. Frontend stores token in `localStorage` (`fitpay_token`) and sends `Authorization: Bearer`. Refresh endpoint available but not yet auto-used on 401 (interceptor clears storage → redirect to login).
- **Role middleware**: `bootstrap/app.php` registers alias `role`; routes use `middleware('role:admin')` / `role:member`. `EnsureRole` handles both `auth('api')` and `auth()` and try/catch for blacklisted/expired tokens → 401. Tests confirm 403 on cross-role access.
- **Seeder**: `DatabaseSeeder` uses `updateOrCreate` so re-seed is idempotent; passwords `password` (bcrypt, 12 rounds). Verified 2 users only after cleanup of temp `test2@fitpay.test` probe.
- **CORS**: `config/cors.php` allows `api/*` from `*` with `supports_credentials false`; frontend uses `withCredentials false` (JWT header). For production, restrict `allowed_origins` to `FRONTEND_URL`.
- **Design.md vs themes.md**: `design.md` is narrative (9 sections, 12px radius, 44px touch target, etc); `themes.md` is the code-faced token file actually imported by `src/index.css`. `design.md` had a trailing task note (2 lines) removed in this commit to keep spec clean — no visual change.
- **Frontend routing**: `/` and `*` redirect role-aware; `/login`/`/register` are public (authed users bounced to their dashboard). Member trying `/admin` gets bounced to `/member` (and backend would also 403 if they forced API). No full route for `/members` etc yet — stubs remain in `frontend/src/pages/Members` etc for next FRs.
- **Mobile-first**: All new pages use `container max-w-[1200px] px-4 sm:px-6`, `grid-cols-1 sm:grid-cols-2 lg:grid-cols-4`, `min-h-11/12`, `Sheet`/`Drawer`, bottom bar `md:hidden`, `font-display` + `tabular-nums` for numbers — verified at 375px/320px via devtools (no horizontal scroll).
- **Validation**: Backend validates `name`, `email unique`, `password confirmed min 8`, `role in admin,member` (defaults member). Frontend surfaces `422` first error in banner + `AlertCircle`. Forms use `h-12` + `rounded-lg` + focus `ring-[var(--charge-500)]/20` per design §5.
- **Follow-ups**: Add refresh-on-401 interceptor (call `/refresh` before logout), add full CRUD pages behind `role:admin` (Members FR-02 etc), add `member` self-service endpoints, add unit/feature tests for auth/role, run `php artisan migrate --seed` in CI, restrict CORS origins, consider `php artisan jwt:secret` rotation.
